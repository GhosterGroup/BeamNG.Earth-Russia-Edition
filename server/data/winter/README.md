# Siberian winter map boundary data

`russia_admin0_50m.geojson.gz` contains the Russia feature from Natural Earth's
1:50m Admin 0 Countries dataset, compressed as GeoJSON. The boundary is used to
keep the winter map treatment within Russia; the Siberia coverage envelope is
then intersected with this country geometry.

Source: <https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries/>

Natural Earth vector data is in the public domain. The source dataset describes
de facto boundaries; its geometry is suitable for regional visual coverage,
not legal or navigational boundary decisions.
